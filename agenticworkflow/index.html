Gen AI: Generative AI

Massive scale statistical pattern matching. Fast, intuitive, preferred for personal writing, editing, and poetic expression.

< 2017
Stochastic Parrot — Autocomplete / predictive modeling
< 2020
GPT-2.0 — Proof of concept for emerging behavior like summarization through self-attention
< 2021
GPT-3 — OpenAI's WebGPT team trained the model to issue commands like "query," which became tool/function calling JSON schema, copied as industry standard
< 2022
GPT-3 → GPT-4 — Reinforcement learning from human feedback allowed for coding and step-by-step reasoning (= recursive logic)
Maastricht University

Res AI: Reasoning AI

Inherited Gen AI methods and put them to the next level.

Test-time compute: They think by spending extra time during the response to search for a solution = chain of thought reasoning. Behaviors such as self-correction, backtracking, and trying alternative approaches emerged.

< 2023
AutoGPT — Used the ReAct loop pattern allowing long horizon planning outside weights by actual tool calling
< 2024
GPT-o1 Preview — First full reasoning model (multimodal) with deep grasp of recursive nesting and expanded context window (128K tokens). Trained with outcome-based rewards.
May 2025
Claude Opus 4.6 — Anthropic releases model explicitly built for hours-long agentic sessions
Autumn 2025
First open-source implementations: OpenCode, personal agents like OpenClaw or PI Coding Agent
Culminating by 2026: Agentic AI = LLM where Res AI sits inside Gen AI and is held in a loop with autocomplete + context window + reasoning (chain of thought) + tool calling + task horizon baked in. The harness is open-sourced.
